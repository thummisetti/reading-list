Lesson 46 — X/C Nav Log Explained

▶ Watch lesson   Back to course

Core idea

  • A navigation log turns a route into leg-by-leg numbers for course, heading, distance, groundspeed, time, and fuel.
  • The point is not paperwork—it gives you expected values to compare against actual progress in flight.

Route and true course

  • Plot checkpoints and measure true course/distance on the sectional.
  • Apply magnetic variation to get magnetic course, then compass deviation as applicable to get compass heading.

Wind correction

  • Use forecast wind and true airspeed to solve wind correction angle and groundspeed.
  • Heading = course corrected for wind; actual track should match desired course.

Time and fuel

  • ETE = distance ÷ groundspeed (convert hours to minutes).
  • Fuel for leg = fuel flow × time, plus taxi/climb/reserve planning as appropriate.
  • Use conservative burn/performance data from POH and actual aircraft experience.

Inflight use

  • Record actual times and compare with planned checkpoints.
  • A growing timing/position error is a cue to reassess wind, heading, or position before becoming lost.

What to remember

  • True course → variation → magnetic course → wind correction → heading.
  • GS determines time; time × fuel flow determines fuel.
  • Update plan with actual progress.
