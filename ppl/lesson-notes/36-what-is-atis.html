Lesson 36 — What is ATIS?

▶ Watch lesson   Back to course

Core idea

  • ATIS is a continuous recorded broadcast of essential terminal information at many towered airports.
  • It reduces frequency congestion by giving pilots routine weather/runway information before contacting ATC.

Typical contents

  • Wind, visibility, ceiling, temperature/dew point, altimeter setting.
  • Runways/approaches in use and important airport operational items.
  • May include closures, braking/bird/lighting information, or special instructions.

Information code

  • Each update gets a phonetic-letter code such as Information Alpha.
  • Tell ATC you have the current code on initial contact.
  • Material changes cause a new broadcast/code.

ATIS vs AWOS/ASOS

  • ATIS is an operational terminal broadcast; AWOS/ASOS are automated weather-observing systems.
  • ATIS does not replace a complete preflight weather/NOTAM briefing.

What to remember

  • Listen before calling.
  • Report the ATIS code.
  • ATIS = weather + terminal/runway information.
