Lesson 17 — Class C Airspace

Class C is the first airspace where the distinction between an explicit clearance and merely established two-way communication really matters: unlike Class B, you do not need the words “cleared into Charlie,” but ATC must respond using your aircraft identification before you enter.

Core idea

  • Class C generally surrounds an airport with an operating control tower, radar approach control, and sufficient IFR/passenger activity to justify radar sequencing/services.
  • It is shown on VFR sectionals by solid magenta lines.
  • Before entering VFR, you must establish two-way radio communication with the ATC facility providing Class C service and maintain communications while inside.
  • Basic VFR weather minimum: 3 SM visibility, 500 ft below / 1,000 ft above / 2,000 ft horizontal from clouds (“3-152”).

Typical shape and dimensions

  • Class C is often described as a smaller upside-down wedding cake.
  • Typical surface core: 5-NM radius, surface to about 4,000 ft above airport elevation.
  • Typical shelf: out to a 10-NM radius, with a floor no lower than about 1,200 ft AGL and the same approximate 4,000-ft-above-airport ceiling.
  • The actual ceiling is charted in MSL, and every Class C is individually tailored; read the sectional rather than relying on generic numbers.
  • You may fly under a shelf and remain outside the Class C if you stay below its charted floor and comply with any other applicable airspace/equipment rules.

The 20-NM outer area

  • Class C facilities normally have a procedural outer area extending roughly 20 NM from the primary airport where radar services may be provided.
  • The outer area is not itself Class C airspace and is not charted as a Class C ring.
  • The instructor uses this distance as a practical place to contact approach early, obtain ATIS, get a squawk code, and be sequenced before reaching the actual boundary.

What counts as “two-way communication established”?

  • If ATC responds using your aircraft identification/call sign, communication has been established for the Class C entry requirement unless ATC specifically tells you to remain outside.
  • Example: “Cessna 6789X, standby” contains the aircraft ID, so communication is established and entry is permitted unless told otherwise.
  • If ATC says only “aircraft calling, standby” or otherwise replies without identifying your aircraft, communication has not been established; remain outside.
  • If ATC explicitly says “remain outside Class Charlie,” do not enter even though two-way communication exists.
  • This is different from Class B, where a specific ATC clearance is required before entry.

Radio-call example from the lesson

  • The instructor has the pilot listen to ATIS first and then contact approach from about 20 NM out.
  • Useful initial-call structure remains: facility → aircraft ID → position → altitude → ATIS code → request/destination.
  • Example structure: “Tulsa Approach, Cessna 6789X, 20 miles northwest, 3,500, with Tango, request straight-in…”
  • ATC may assign a transponder code, radar identify the aircraft, issue headings/altitudes, provide traffic sequencing, and hand the pilot to tower as the flight approaches the airport.
  • Do not wait until the Class C boundary to make the first call; initiate contact far enough out that a failed/busy call does not cause an inadvertent entry.

Equipment

  • An operable two-way radio is required.
  • Unless otherwise authorized by ATC, an operable transponder with automatic altitude reporting and ADS-B Out are required for Class C operations under current rules.
  • Transponder/ADS-B requirements can also apply above Class C or in nearby airspace even when you are not physically inside the Class C itself; check §§91.215 and 91.225.

ATC services and pilot responsibilities

  • Class C services include radar sequencing and traffic information/separation services appropriate to the traffic mix.
  • VFR aircraft are generally sequenced to the primary airport and receive traffic advisories as required/workload permits.
  • VFR pilots still retain responsibility for see-and-avoid, VFR weather, terrain/obstruction clearance, wake avoidance, and safe operation.
  • Follow assigned headings/altitudes unless unable; if an instruction would compromise safety or VFR, advise ATC.

Speed considerations

  • Under 14 CFR 91.117, aircraft generally may not exceed 250 KIAS below 10,000 ft MSL.
  • At or below 2,500 ft AGL within 4 NM of the primary airport of Class C or D airspace, the general limit is 200 KIAS unless otherwise authorized/required by regulation.
  • These speed rules are not the same thing as the Class C lateral boundary; they are separate operating limitations.

Accuracy notes

  • The transcript simplifies the communication test as hearing your “full call sign.” The FAA standard is that the controller responds with the aircraft identification; it need not always be every character after abbreviations have been established.
  • Do not treat the typical 5/10-NM rings as guaranteed geometry. Actual charted Class C dimensions control.
  • “Standby” does not mean ATC has begun providing every Class C service immediately; it means the two-way-communication entry requirement has been met if your aircraft ID was used and you were not told to remain outside.

Worth watching — sectional and radio scenarios

  • The solid-magenta ring/shelf sectional example is worth seeing once to practice vertical floor/ceiling interpretation.
  • The “aircraft calling, standby” versus “[your callsign], standby” comparison is one of the most useful visual/audio examples in the lesson because it tests the exact Class C entry rule.

What to remember for review

  • Solid magenta boundaries.
  • Typical 5-NM core / 10-NM shelf / 4,000 ft above airport elevation; chart controls.
  • Two-way communication established before entry.
  • Your aircraft ID in ATC's response = communication established unless told to remain outside.
  • No aircraft ID in the response = stay outside.
  • 3 SM / 500 below / 1,000 above / 2,000 horizontal.
  • Radio + applicable transponder/altitude reporting + ADS-B Out.
  • 20-NM procedural outer area is not itself Class C.
