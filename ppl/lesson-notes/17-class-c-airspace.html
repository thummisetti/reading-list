Lesson 17 — Class C Airspace

Comprehensive condensed study notes for Josh Campbell / Free Pilot Training.

▶ Watch lessonBack to course
Low-bandwidth review notes: preserve the lesson’s core instructional material, definitions, relationships, and practical implications while removing repetition and filler.

Core idea

  • Class C surrounds airports with an operating control tower, radar approach control, and a certain level of IFR activity.
  • VFR entry requires two-way radio communication established with ATC before entry.

Typical dimensions

  • Commonly a 5-NM surface core and a 10-NM shelf from about 1,200 feet to 4,000 feet above airport elevation, but actual dimensions vary.
  • A 20-NM outer area is associated with radar services but is not itself Class C airspace.

Communication

  • Two-way communication is established when ATC responds with your aircraft callsign.
  • If ATC responds only with 'aircraft calling, standby' without your callsign, communication has not been established for entry.

Equipment

  • Two-way radio and appropriate transponder/altitude-reporting equipment are generally required; ADS-B Out requirements apply where specified.
  • Check §91.130 and §91.215/225 plus the chart for the actual operation.

Weather

  • Basic VFR: 3 SM, 500 below, 1,000 above, 2,000 horizontal.

What to remember

  • Solid magenta boundaries.
  • Establish two-way communication before entry.
  • Typical 5-NM core / 10-NM shelf, but chart controls.
  • 3-152 weather minima.
