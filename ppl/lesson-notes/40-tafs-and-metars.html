Lesson 40 — TAFs and METARs

▶ Watch lesson   Back to course

Core idea

  • METAR = current/recent observed airport weather; TAF = terminal forecast for a defined period.
  • Both use compact coded groups; learn the order rather than decoding randomly.

METAR order

  • Station identifier → date/time Z → wind → visibility → runway visual range if present → weather → sky condition → temperature/dew point → altimeter → remarks.
  • Wind example 22012G20KT = from 220° true at 12 kt, gusting 20.
  • Sky: FEW/SCT are not ceilings; BKN/OVC (and vertical visibility) can define a ceiling.
  • A2992 = 29.92 inHg.

Weather codes

  • Intensity/proximity + descriptor + precipitation/obscuration/other codes combine: e.g. -RA, TSRA, BR, FG.
  • SM visibility is statute miles; cloud bases are hundreds of feet AGL.

TAF

  • TAF begins with station and issue/valid times, then forecast wind/visibility/weather/clouds.
  • FM = from (rapid transition); TEMPO = temporary fluctuations; PROB when used = probability group.
  • Read every change group across your ETA window, not just the first line.

Use

  • METAR/TAF are only pieces of a weather picture; combine them with radar/satellite, GFA, PIREPs, advisories, winds, and trends.

What to remember

  • METAR observes; TAF forecasts.
  • Decode in group order.
  • BKN/OVC/vertical visibility matter for ceilings.
  • Always evaluate forecast changes around ETA.
