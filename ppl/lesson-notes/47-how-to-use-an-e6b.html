Lesson 47 — How to Use an E6B

▶ Watch lesson   Back to course

Core idea

  • The E6B is a circular slide rule plus wind side used to solve common aviation planning calculations.
  • Understand the relationships so you can sanity-check any mechanical/electronic answer.

Time, speed, distance

  • Rate triangle: distance = speed × time.
  • On the calculator side, set rate opposite the index and read distance/time relationships on matching scales.
  • Watch units: minutes vs hours, NM vs statute miles, knots vs mph.

Fuel

  • Set gallons-per-hour as rate; align time to read gallons used, or gallons available to read endurance.
  • Add legal/operational reserve rather than planning to empty tanks.

Conversions / density altitude / TAS

  • E6B scales handle NM-SM-km, gallons/pounds for known fuel density, temperature, and other conversions.
  • Traditional E6B workflows can estimate true airspeed and density altitude from pressure altitude/temperature.

Wind side

  • Plot wind direction/speed, set true course/TAS, then determine wind correction angle and groundspeed.
  • Apply WCA left/right to course to get heading.

What to remember

  • Keep units straight.
  • Distance = speed × time.
  • Fuel = flow × time.
  • Wind side gives WCA + groundspeed.
