Lesson 38 — GPS Navigation Explained

▶ Watch lesson   Back to course

Core idea

  • GPS — Global Positioning System uses timed satellite signals to determine aircraft position and support area navigation.
  • Modern GPS can make navigation look effortless, but safe use still requires correct waypoint selection, source/mode awareness, integrity monitoring, database awareness, and a backup plan.

How GPS finds position

  • Each satellite transmits precise timing/orbit information.
  • The receiver measures signal travel time and converts that timing into an estimated distance from each satellite.
  • Using multiple distance measurements, the receiver solves position through trilateration.
  • A practical 3-D GPS solution needs enough satellite measurements to solve latitude, longitude, altitude, and receiver-clock error; satellite geometry affects solution quality.

GPS vs VOR

  • VOR navigation is tied to radials from ground stations and line-of-sight coverage.
  • GPS permits area navigation (RNAV): routes can connect database waypoints without flying directly over ground navaids.
  • GPS directly provides position, course/track, groundspeed, distance, and time estimates that would require multiple sources/calculations with older navigation.

Common navigation functions

  • Direct-To: creates a course from current position to a selected waypoint.
  • Flight plan: sequences multiple waypoints/legs.
  • Nearest: rapidly identifies nearby airports/facilities—useful in diversion/emergency planning.
  • Typical displays include desired track/course, actual ground track, cross-track error/CDI, distance, groundspeed, ETA/ETE, bearing, and waypoint sequence.

Waypoint verification

  • Typing a valid identifier does not prove it is the intended airport/fix. Duplicate/similar identifiers and nearby waypoints can create dangerous errors.
  • Before activating Direct-To or a flight plan, verify identifier, name/location, bearing/distance, and route geometry against the chart/plan.
  • After activation, look at the moving-map/course line and ask: does this route make geographic sense?

CDI / course guidance

  • GPS course deviation works similarly to VOR CDI conceptually—needle/bar displacement tells whether the desired course is left/right—but GPS scaling can change by phase of flight and equipment.
  • On a glass HSI, verify the active navigation source is GPS, not VLOC/VOR, before following GPS guidance.
  • Do not confuse heading with ground track: wind can require a crab angle to maintain the GPS course.

WAAS

  • WAAS — Wide Area Augmentation System uses a network of ground reference stations and correction/integrity messaging to improve GPS accuracy, integrity, and availability.
  • WAAS-capable aviation receivers can support more precise navigation/approach functions when the installation and procedure authorize them.

RAIM / integrity

  • Non-WAAS IFR GPS installations may use RAIM — Receiver Autonomous Integrity Monitoring to determine whether available satellite geometry/data can support reliable navigation.
  • A GPS position without required integrity is not the same as a valid navigation solution for the intended operation.
  • Know the receiver's integrity-loss annunciations and what action the pilot guide requires.

Database currency

  • Aviation GPS databases contain airports, navaids, fixes, procedures, and other coded data. Information can become obsolete as the NAS changes.
  • For VFR, an old database can still mislead situational awareness; cross-check current charts/NOTAMs.
  • For IFR/procedure use, database currency and approved equipment/installation requirements are more restrictive—follow current rules and the avionics authorization.

Outages, interference, and NOTAMs

  • GPS is not invulnerable. Testing, interference/jamming, equipment failure, antenna issues, or constellation/integrity problems can reduce or eliminate service.
  • GPS interference/outage information can be published by NOTAM. A preflight check should include navigation-system status relevant to the route.

Backup and overreliance

  • A moving airplane icon is not proof the database, route, or receiver is correct.
  • Maintain basic pilotage/dead-reckoning awareness and know available alternate navigation resources.
  • If the GPS fails, you should still know approximately where you are, what terrain/airspace surrounds you, and how to continue/divert safely.
  • In VFR, keep the outside traffic scan; GPS screens can create strong heads-down fixation.

Accuracy note — position solution

  • The transcript simplifies trilateration as progressively intersecting distance spheres. That is useful intuition, but an aviation receiver also solves clock error and applies satellite/navigation corrections; do not reduce operational integrity to “three satellites means position is good.”

What to remember

  • GPS uses timed satellite ranging + trilateration.
  • Verify waypoint identity and route geometry before activation.
  • Direct-To/flight plans/nearest are tools—not substitutes for situational awareness.
  • WAAS improves accuracy/integrity/availability; RAIM is an integrity concept on applicable systems.
  • Know the active nav source and CDI scaling/annunciations.
  • Check database and outage/NOTAM status.
  • Keep a backup navigation plan.
