Lesson 20 — Class G Airspace

Comprehensive condensed notes for Josh Campbell / Free Pilot Training — merged from the full lesson transcript, the existing study notes, and current FAA guidance.

Class G is uncontrolled, not unregulated. The biggest study challenge is locating the Class G/Class E boundary and applying the correct weather minimum for altitude and day/night.

Core idea

  • Class G is the portion of airspace that has not been designated Class A, B, C, D, or E.
  • It is called uncontrolled airspace because ATC does not provide the same controlled-airspace structure/separation service there.
  • You do not need an ATC clearance or two-way-radio establishment merely to enter Class G VFR.
  • Federal operating rules still apply: weather minimums, minimum safe altitudes, right-of-way, aircraft/pilot rules, and other applicable regulations do not disappear.

Accuracy note — “ATC has no authority” is too broad

  • The transcript says ATC has “no authority or responsibility to control air traffic” in Class G.
  • The useful point is that Class G is not controlled airspace and ATC does not provide standard IFR separation there merely by virtue of the class.
  • Do not interpret “uncontrolled” as “ATC can never issue or coordinate anything involving a Class G operation” or “no regulations apply.” IFR clearances/services can interact with Class G operations, and pilots remain subject to the FARs.

Where Class G is found

  • Class G commonly begins at the surface and extends upward to—but does not include—the base of the overlying Class E.
  • In many parts of the country, Class E starts at 700 ft AGL or 1,200 ft AGL, leaving Class G beneath it.
  • In some areas, especially remote locations, Class G can extend higher before Class E begins.
  • You identify Class G largely by identifying where controlled airspace does not begin; sectionals do not outline every Class G parcel with its own dedicated boundary style.
  • The transcript recommends the FAA Aeronautical Chart User's Guide as a reference for interpreting sectional symbology.

Class D can become Class G when the tower closes

  • The lesson revisits part-time Class D airports.
  • A published Class D surface area may revert to Class G when the tower closes if that is the designated after-hours status.
  • The instructor demonstrates checking the Chart Supplement airspace/tower-hours entry to determine when that change occurs.
  • Another part-time Class D may instead revert to Class E, so never assume the after-hours class from the sectional alone.

Class G weather minima — 1,200 ft AGL or less

  • For airplanes during the day, at 1,200 ft or less above the surface: generally 1 SM visibility and clear of clouds.
  • At night in the same altitude band, the general airplane minimum is 3 SM and 500 below / 1,000 above / 2,000 horizontal, subject to the specific §91.155(b) nighttime airport-pattern exception.
  • The transcript emphasizes that the 1,200-ft test is measured above the surface (AGL), regardless of the airplane's MSL altitude.

More than 1,200 ft AGL but below 10,000 ft MSL

  • During the day: generally 1 SM visibility and 500 below / 1,000 above / 2,000 horizontal from clouds.
  • At night: generally 3 SM and the same 500-below / 1,000-above / 2,000-horizontal cloud clearance.
  • The distinction is easy to miss: above 1,200 AGL, daytime Class G is no longer “clear of clouds”; cloud separation is required.

More than 1,200 ft AGL and at/above 10,000 ft MSL

  • General airplane minimum: 5 SM visibility.
  • Cloud clearance: 1,000 ft below, 1,000 ft above, 1 statute mile horizontal.
  • The larger spacing reflects the higher operating speeds and need for more time/distance to see and avoid traffic near clouds.

Memory structure for the weather table

  • Start with two questions: Am I within 1,200 ft of the surface? and Am I below 10,000 ft MSL?
  • Then ask day or night?
  • Day ≤1,200 AGL is the memorable permissive case: 1 SM / clear of clouds.
  • Above 1,200 AGL but below 10,000 MSL, cloud clearances become 500/1,000/2,000; visibility is 1 SM day and 3 SM night.
  • At/above 10,000 MSL (while >1,200 AGL), think 5 SM / 1,000-1,000-1 mile.
  • Use the current §91.155/AIM table for actual planning because helicopter and specific nighttime exceptions add detail beyond the airplane memory pattern.

IFR can exist in Class G

  • “Uncontrolled” does not mean IFR flight is prohibited.
  • IFR operations in Class G must meet applicable pilot, aircraft, altitude, and other IFR rules.
  • ATC separation is not provided merely because an airplane is IFR in uncontrolled airspace, so understanding where controlled airspace begins is important for IFR procedure design/clearances.

See-and-avoid / practical implications

  • Class G can contain aircraft operating without ATC communication or radar service.
  • VFR pilots must maintain vigilant see-and-avoid, especially near nontowered airports, practice areas, agricultural operations, and other low-altitude traffic.
  • Legal minimum weather may still be a poor personal minimum. Very low visibility and “clear of clouds” can leave little reaction time around terrain, towers, wires, birds, and traffic.

Worth watching — sectional / Chart Supplement examples

  • The lesson visually shows how to infer Class G from the base of overlying Class E rather than looking for a dedicated “G boundary.”
  • The part-time tower example is useful for learning the habit of checking the Chart Supplement rather than assuming a towered airport's airspace class is constant 24/7.

What to remember for review

  • Class G = uncontrolled, not unregulated.
  • Usually surface to the base of overlying Class E.
  • Part-time Class D can revert to G when published.
  • ≤1,200 AGL day: 1 SM / clear of clouds.
  • ≤1,200 AGL night: generally 3 SM / 500-1,000-2,000, with a specific regulatory airport-pattern exception.
  • >1,200 AGL and <10,000 MSL: 1 SM day or 3 SM night, both 500-1,000-2,000.
  • >1,200 AGL and ≥10,000 MSL: 5 SM / 1,000 below / 1,000 above / 1 SM horizontal.
  • Use the current FAA table for final planning and test nuance.
