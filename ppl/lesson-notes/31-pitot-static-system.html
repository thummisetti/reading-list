Lesson 31 — The Pitot-Static System

▶ Watch lesson   Back to course

Core idea

  • The pitot-static system uses air pressure to operate three primary instruments: airspeed indicator (ASI), altimeter, and vertical speed indicator (VSI).
  • The system compares/uses static (ambient) pressure and pitot/total pressure.

Pressure concepts

  • Static pressure is ambient atmospheric pressure surrounding the aircraft. It exists whether the airplane is moving or stopped and generally decreases with altitude.
  • Dynamic pressure is associated with motion through the air and increases strongly with airspeed.
  • Total (pitot) pressure is static pressure plus dynamic/ram pressure at the pitot opening.

Pitot tube and static ports

  • The pitot opening faces the relative airflow and captures total/ram pressure.
  • A pitot drain opening allows moisture to escape; configuration varies by aircraft.
  • Static ports are placed where airflow disturbance is minimized so they can sense ambient pressure accurately.
  • Preflight: verify pitot and static openings are clear and remove any cover before flight.

Which instrument uses what?

  • ASI: compares pitot total pressure against static pressure; the difference represents dynamic pressure and is calibrated as airspeed.
  • Altimeter: uses static pressure only; sealed aneroid wafers expand/contract as ambient pressure changes.
  • VSI: uses static pressure both directly and through a calibrated restriction/leak; the temporary pressure difference measures rate of pressure change and therefore vertical speed.

Pitot blockage

  • If the main pitot opening is blocked but its drain remains open, pitot pressure can vent and the ASI tends toward zero.
  • If both pitot inlet and drain are blocked, pressure becomes trapped. The ASI then behaves somewhat like an altimeter: it tends to indicate higher airspeed in a climb and lower airspeed in a descent even if actual airspeed is unchanged.
  • The altimeter and VSI are unaffected by a pitot-only blockage because they use the static system.
  • Pitot heat helps prevent/remove ice on the heated pitot head when used according to the POH/AFM.

Static blockage

  • If the static source becomes completely blocked, the altimeter freezes at the pressure altitude where blockage occurred.
  • The VSI trends to zero after transient effects because no continuing pressure change reaches the system.
  • The ASI becomes erroneous: with trapped static pressure it generally underreads in a climb and overreads in a descent relative to the value it would show with a functioning static source.

Alternate static source

  • Some airplanes have an alternate static source, often drawing cabin air, that can restore operation after an external-static blockage.
  • Cabin pressure may differ from true outside static pressure, so the instruments can show predictable errors when alternate static is selected.
  • Use the POH/AFM for the installed system's procedure and correction information.

Failure diagnosis by grouping

  • ASI wrong by itself: suspect pitot side first.
  • Altimeter + VSI + ASI all acting abnormally together: suspect the static side.
  • Glass panels still depend on air-data sensors connected to pitot/static sources, so a digital display does not eliminate pitot-static failure modes.

What to remember

  • Pitot + static → ASI; static only → altimeter/VSI.
  • Pitot blocked/drain open → ASI toward zero.
  • Pitot + drain blocked → ASI acts altitude-sensitive.
  • Static blocked → altimeter freezes, VSI → zero, ASI erroneous.
  • Know pitot heat and alternate-static procedures for the actual airplane.
