Lesson 31 — The Pitot-Static System

▶ Watch lesson   Back to course

Core idea

  • Pitot-static pressure feeds the airspeed indicator, altimeter, and VSI.
  • Pitot senses ram/total pressure; static ports sense ambient pressure.

Which instrument uses what

  • ASI compares pitot total pressure with static pressure.
  • Altimeter uses static pressure.
  • VSI uses static pressure plus a calibrated leak to sense pressure-change rate.

Pitot blockage

  • Pitot blocked but drain open: pressure can vent and ASI tends toward zero.
  • Pitot and drain both blocked: trapped pitot pressure can make ASI respond incorrectly with altitude changes.
  • Pitot heat protects against icing when used per POH.

Static blockage

  • Altimeter tends to freeze; VSI tends to zero.
  • ASI becomes erroneous because trapped static pressure no longer matches ambient pressure.
  • Alternate static source may restore function with predictable error.

What to remember

  • Pitot+static → ASI; static → altimeter/VSI.
  • Know blockage symptoms.
  • Check pitot/static openings on preflight.
